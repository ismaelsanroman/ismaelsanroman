## 🧩 Sobre mí

Ahora mismo trabajo como **Quality Lead**: soy responsable de la estrategia de calidad y la lidero de principio a fin. Eso incluye decidir cómo y dónde se prueba cada cosa, montar la plataforma de testing con la que trabajan los equipos y conseguir que la calidad deje de ser "lo que se mira al final" y pase a ser parte del día a día.

Vengo del mundo **SDET**, así que me gusta mancharme las manos: diseño frameworks, escribo tests, monto pipelines, lanzo pruebas de carga y, últimamente, pongo a trabajar a **agentes de IA** para que el equipo vaya más rápido sin perder calidad.

Mi enfoque es sencillo: **estabilidad, trazabilidad y datos objetivos** para que negocio y desarrollo tomen decisiones con confianza.

---

## 💼 Qué hago ahora

### 🏗️ Estrategia y liderazgo de calidad
- Defino y lidero la **estrategia de calidad** para varios productos digitales y sus APIs compartidas.
- He escrito los **handbooks de calidad** para QA y para desarrollo: qué probar, en qué capa, con qué prioridad y qué debe bloquear una release.
- Diseño la **arquitectura de repositorios de test** y convierto **PRD y RFC** en planes de prueba y tareas trazables en **Azure DevOps**.

### 🧰 Plataforma de testing reutilizable
- He creado un **toolkit en TypeScript** que comparten todos los repos de automatización, con sus propias **CLIs** para crear, sincronizar y diagnosticar proyectos de test.
- Mismo stack, mismas reglas y mismos informes para todos los equipos: scaffolding, linting, validación de configuración y entornos, y un **Quality Report** propio pensado tanto para QA como para negocio.

### 🧪 Automatización UI + API
- Frameworks con **Cucumber/Gherkin + Playwright + TypeScript**, cubriendo front y back con el mismo stack.
- Page Objects, clientes de API, builders, assertions reutilizables, limpieza automática de datos y ejecución en varios entornos.
- Informes con **Allure**, logging estructurado y quality gates antes de ejecutar nada.

### 🚀 Performance Engineering
- Pruebas de **carga, estrés, capacidad y breakpoint** con **JMeter** sobre microservicios, APIs y journeys completos de usuario.
- Ejecución en cloud con **Azure Load Testing** y en local contra mocks con **Mockoon**.
- Análisis de resultados (p95/p99, errores, throughput) y correlación con métricas de infraestructura para encontrar dónde está el límite real.

### ⚙️ CI/CD
- **Azure Pipelines** con validación estática, ejecución por tags, publicación de informes y bloqueo automático si la calidad no llega.

### 🤖 IA aplicada a QA
- Creo **skills para agentes de IA** (Claude Code, Codex, Devin…) que generan y revisan features, steps, planes de carga, PRD/RFC y tareas de Azure DevOps de forma homogénea.
- Impulso que todo el equipo de ingeniería comparta y reutilice ese conocimiento.
